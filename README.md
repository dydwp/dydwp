### 🖥 Web

🏋️ **개인 맞춤형 운동 관리 웹 서비스, EasyFit** `Spring Boot` `MySQL` `JPA` `Thymeleaf` `Spring Security` `OAuth2`
> "원하는 운동 부위를 한눈에 파악하기 어렵고 초보자는 운동 방법을 알기 어렵다는 문제에서 출발해, 캘린더와 메모로 운동 기록을 관리할 수 있게 만든 개인 프로젝트입니다."

🧑‍💻 **주요 작업**

[기획, 설계, 풀스택 구현]

- MuscleWiki 스타일 SVG 신체 부위 지도와 캘린더 기반 운동 기록·메모 기능 설계 및 구현
- 정적 프론트엔드(HTML/CSS/Vanilla JS) 프로젝트를 Spring Boot REST API 기반으로 전환
- Entity → Repository → Service → Controller 계층형 아키텍처 적용
- Spring Security + OAuth2 기반 로그인 기능 구현
- UML 유스케이스 다이어그램, 화면설계서, ERD, MySQL DDL 등 설계 문서 작성

📌 프로젝트 링크: [easy-fit](https://github.com/dydwp/easy-fit)
